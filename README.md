# Карта изучения программирования

Карта-навигатор по программированию на Python для школьников. Спецификация — задача №1 в трекере.

## Запуск

Нужен Node.js 22 или новее.

```bash
npm install
npm run dev
```

Сайт откроется по адресу http://localhost:5173. Правки файлов карты сразу видны на странице.

## Данные карты

Лежат в `data/map`:

- `sections/*.yaml` — по файлу на раздел. Разделы идут в порядке имён файлов, поэтому имена начинаются с номера (`01-…`, `02-…`). Узлы внутри раздела идут в порядке, в котором записаны.
- `goals.yaml` — цели и их ступени. Ступень задаётся списком целевых узлов.

Узел описывается так:

```yaml
- id: digits-of-number          # постоянный идентификатор; не менять после публикации
  kind: topic                   # topic — тема, ege-task — задание ЕГЭ
  title: Цифры числа
  description: Разбор числа на цифры с помощью деления и остатка в цикле.
  prerequisites: [while-loop, input-numbers]
  materials:
    - title: Название материала
      url: https://…
  checkTasks:
    - title: Название задачи
      url: https://…
```

У задания ЕГЭ есть ещё `egeNumber` — номер задания. Он только подпись, и его можно менять. Пустые списки можно не писать.

## Проверки

```bash
npm test          # тесты ядра логики карты
npm run test:e2e  # сквозные тесты сайта в браузере (на своей учебной карте из tests/e2e/map)
npm run build     # проверка типов и сборка сайта в dist/
```

Перед первым запуском `test:e2e` нужно один раз поставить браузер: `npx playwright install chromium`.

## Устройство

- `src/core` — ядро логики карты: все правила, без зависимостей от интерфейса и браузера.
- `src/layout` — раскладка графа на экране.
- `src/app` — интерфейс на React.
- `tools` — чтение файлов карты с диска и подключение их к сборке.
